# EduSaarthi – Student Dropout Early-Warning System

**Tagline:** Predict Early. Intervene Wisely. Keep Students Learning.

EduSaarthi is an AI-powered student support platform designed to identify students who may be at risk of dropping out and help educational institutions provide timely academic and financial assistance.

## Key Features
- Student management and academic dashboard.
- Student dropout risk analysis.
- AI-based risk prediction (ML integration).
- Academic intervention and mentor tracking.
- What-If risk simulation.
- Financial assistance and NGO matching (planned).
- Reports and CSV export.

## Tech Stack
- **Frontend:** React.js, Vite, Tailwind CSS
- **Backend:** Python, Flask (planned integration)
- **Database:** MySQL (planned integration)
- **Machine Learning:** Python, Scikit-learn
- **Charts:** Recharts

## Installation

```bash
git clone <your-repository-url>
cd edusaarthi
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

## Project Status
Current prototype includes frontend dashboards, student management, rule-based risk categorization, intervention tracking, and reporting. ML integration, backend, database, and NGO matching are under development.
